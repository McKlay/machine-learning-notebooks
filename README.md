# machine-learning-notebooks

This repository reflects my hands-on journey in building, tuning, and interpreting machine learning models, from simple decision trees to deep neural networks.

## Highlights

### Classical ML (`classical-ml/`)
Explore interpretable and foundational models like:
- Decision Trees & Random Forests
- Logistic Regression & KNN
- SVM with RBF kernels
- Gradient Boosting
- Model selection with Grid Search, StratifiedKFold, and PR-AUC

Each notebook includes:
- Clean preprocessing pipelines
- Real Kaggle datasets (e.g., HAR, Credit Card Fraud)
- Evaluation beyond accuracy (precision, recall, F1, ROC, PR curve)
- Threshold tuning and hyperparameter search

### Deep Learning (`deep-learning-ml/`)
Hands-on projects using:
- CNNs with PyTorch & TensorFlow
- Transfer Learning (EfficientNet, MobileNetV2)
- Image Classification & Data Augmentation
- Hugging Face deployment and Gradio apps (where applicable)
